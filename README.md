A one-page newspaper that sums up the world news of Sunday 22 November 2026: the Iranian strike on Bahrain, Mexico's capture of 'El Chapo Isidro', the EU–Indonesia trade deal, the ATP Finals decider, the Gaza aid call, Eisenkot's government bid, and the strike on Lviv. Drawn in Python with Pillow (draw22.py) from the day's verified reporting; main.py copies the finished page to the grader's output path, byte for byte, every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
